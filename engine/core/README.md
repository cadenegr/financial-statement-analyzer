[github.com/cadenegr/skyscrapers](https://github.com/cadenegr/skyscrapers),
folder `engine/core/`, commit `42291ee` (2026-11-05). MIT licence, see
`LICENSE` here.

Do not change them here: change the engine there, then copy the files again
and update the commit above. The map plug-in in `../map/` is copied from
deutsch-sarge-drill (`engine/sentence/main.c`); it knows no German and no
accounting, it only reads a map of cells, groups and candidates.
